## 🛠️ Technologies Used

* **HTML5:** Semantic elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`), forms, and accessible attributes.
* **CSS3:** Box model, custom styling, CSS variables, transitions, Flexbox, and Grid layouts.
* **Bootstrap 5:** Responsive grid system, navbar, cards, forms, buttons, and utility classes.
* **JavaScript (ES6+):** Arrow functions, event listeners, DOM manipulation, `forEach()` iteration, and regular expressions.

---

## ✨ Key Features

1. **Responsive Navbar:** Includes clean navigation links and a toggle button for mobile responsiveness.
2. **Hero Section:** Personal introduction with dynamic call-to-action buttons.
3. **About Me:** Brief professional overview highlighting interests in software development, web technologies, data science, and machine learning.
4. **Education Table:** A structured, responsive table showcasing academic background and current status.
5. **Skills Section:** Organized cards categorized into Programming, Web Development, and AI/Data Science.
6. **Projects with Dynamic Filtering:** Displays projects (*Mental Health Prediction*, *Student Stress Guardian*, *MovieMatch AI*) with functional category filters (**All**, **Web**, **UI**, **App**).
7. **Interactive Light/Dark Mode:** Dynamic theme switcher updating UI colors seamlessly.
8. **Contact Form with Client-Side Validation:** Form validating Name, Email, Subject, and Message fields, returning clear error/success feedback.
